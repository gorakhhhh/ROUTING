# Cisco Routing Practical Guide – CCNA

Welcome to my Cisco Routing practical repository! 🚀

This repository contains hands-on networking labs and configuration examples for CCNA students, networking beginners, and IT professionals.

## 📚 Topics Covered

- **Static Routing** – Manually configure routes between networks.
- **Dynamic Routing** – Learn dynamic route exchange.
- **RIP** – Configure Routing Information Protocol.
- **OSPF** – Configure Open Shortest Path First.
- **EIGRP** – Configure Enhanced Interior Gateway Routing Protocol.
- **ACL (Access Control List)** – Control network traffic using access rules.

## 🎯 Learning Objectives

- Understand routing concepts and protocols.
- Configure routers using Cisco IOS commands.
- Practice network connectivity and troubleshooting.
- Develop practical networking skills for CCNA preparation.

## 🛠️ Technologies

Cisco Packet Tracer | Cisco IOS | IP Routing | ACL | RIP | OSPF | EIGRP
